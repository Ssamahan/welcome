## 9. What ISO 15189:2022 actually requires (checked, not assumed)

The user said *"Forms are reviewed after a month & filed. Check what iso says!"* The
standard splits this in two and conflating it is a common finding:

| Clause | Applies to | Requirement |
|---|---|---|
| **8.3.2** | the **blank form** (a document) | uniquely identified; approved for adequacy **before issue**; **"periodically reviewed and updated as necessary"** |
| **8.4.3** | the **completed form** (a record) | retention times **specified**; legible, retrievable, protected |

ISO does **not** prescribe a numbering scheme. 8.3.2 a) says only *"documents are
uniquely identified"* — which is why the duplicate 049 and the 008 collision are real
nonconformities, and why a clean sequential series is good practice but not mandated.

**Design decision taken with the user:** each form's "How to use" sheet now carries

1. **Review and sign-off block** — version, month reviewed, date, reviewer, signature,
   finding, version-changed Y/N. Six rows. Reviewed monthly; the version changes
   **only when the review finds something that must change**, because ISO says *as
   necessary* — re-issuing monthly would leave no demonstrable current version.
2. **"Days not recorded" register** — every day the log was not completed, with reason,
   action, who it was reported to, and closure. The user's stated purpose: *"this will
   help me track if there were a day with unrecorded preventive maintenance or
   temperature log."* A blank box cannot distinguish "done but not written" from
   "missed"; this register can.

**Known limitation, stated to the user and not yet closed:** the register catches
omissions; it does not *prove* coverage. If every day must be provably covered, the
monthly sheets need the day initialled even when no task was due. The user has not
asked for that yet.

## 10. Gotchas that cost time — read before editing

These are all real failures from this session. Do not rediscover them.

### python-docx / OOXML

- **Element order inside `w:tblPr` is enforced.** `w:tblBorders` must come **before**
  `w:tblLook`. Appending it puts it out of schema order and Word can report the file as
  damaged. Insert with `tblLook.addprevious(borders)`. This shipped once and had to be
  fixed and re-uploaded.
- **Footer ordering:** appending footer runs before the final footer assignment is
  silently wiped. Write the footer **last** inside `base_doc`.
- **`w:fldSimple`** for page numbers needs `OxmlElement("w:fldSimple")` +
  `set(qn("w:instr"), " PAGE ")`. `p.text` will render "Page  of " — expected.
- Merged cells scramble `row.cells` text extraction. Deduplicate runs of identical
  adjacent cells before parsing.
- Image sizes are in EMU: `cm = emu / 360000`.

### Bulk re-coding

- **Line-wrapped string literals defeat `str.replace`.** After any bulk rename, grep for
  trailing fragments.
- Renumbering with chained replacements corrupts (`053→050` then `054→051` can collide).
  **Park each old value in a unique sentinel first, then unpark.** A hex-colour guard
  like `(?<![0-9A-Fa-f])050(?![0-9A-Fa-f])` prevents `0563C1` (a link colour) being
  rewritten.
- `edit_file` needs literal text. For awkward patches use a Python heredoc with
  `assert old in s`.

### Drive / Docs connectors

- `list_files` has **no `folder_id`** — use the `q` parents query.
- `search_files` rejects `q`; it takes `query`.
- **`upload_file` rate-limits at roughly 1–4 per reply.** Batch accordingly.
- `read_file_text` returns **no images** and truncates at `max_chars`. For embedded
  media, `download_file` the `.docx` and unzip `word/media/`.
- `export_file` only works on native Google Workspace files, **not** on an uploaded
  `.docx`. For a stored binary use `download_file`.
- **Never trash a Drive file before its replacement is uploaded.**
- `google_docs.replace_text` returns `success:true` with an **empty** `replaceAllText:{}`
  when nothing matched. An em-dash mismatch caused exactly this — check
  `occurrencesChanged`, and `find_text` first when unsure.
- `trash_file` 403 is not retryable. **Never reconstruct a file ID.**

### Environment

- Packages reset between turns: `pip install python-docx openpyxl`.
- Pillow needs `--break-system-packages`.
- No LibreOffice, so **no PDF render to eyeball the layout.** Verify geometry
  numerically, or compose a preview with PIL (see §13).
